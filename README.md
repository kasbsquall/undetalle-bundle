# Arma tu arreglo · prototipo

Prototipo funcional del sistema de bundle para Undetalle: el cliente arma su
propio arreglo floral eligiendo formato, flores, follaje y extras, y gana
descuento por tramos según lo que va sumando.

Es una maqueta que funciona, no una tienda. No hay stock real, no hay cobro
real y la configuración no se guarda.

## Qué incluye

- Cuatro pasos: presentación, flores y follaje, extras y mensaje
- Carrito en vivo con tramos de descuento (0, 5, 10 y 15%) y envío gratis desde S/ 80
- Vista previa del arreglo, que se va llenando con lo que el cliente elige
- Checkout simulado con las pasarelas reales de la tienda
- Página de agradecimiento con el pedido completo
- Pantalla de configuración, para mostrar cómo se administra

## Para correrlo en local

```
npm install
npm run dev
```

## Publicación

Cada envío a `master` se publica solo en GitHub Pages.
